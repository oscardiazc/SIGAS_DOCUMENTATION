The Attendance History module gives you a complete, filterable record of every confirmed appointment ever scheduled in SIGAS. Use it to review what happened on a specific day, produce monthly statistics for a clinical box, or look up the appointment history for a specific patient. Unlike the patient-level view (which focuses on one person), this page shows all appointments across all boxes and all patients within the filters you apply.

## Accessing the Module

Navigate to **Panel Admin → Historial Horas** from the main sidebar.

---

## What the History Shows

Every row in the attendance table represents a single confirmed appointment. The table displays the following columns:

| Column | Description |
|--------|-------------|
| **Fecha** | The appointment date in `DD/MM/YYYY` format |
| **Horario** | The start and end times of the appointment slot (e.g., `08:40 - 08:50`) |
| **Box** | The clinical box number where the appointment was held |
| **Paciente** | The patient's full name, RUT, and phone number |
| **Tipo Atención** | The care type, shown with a colour-coded indicator matching the schedule colours |
| **Unidad / Previsión** | The patient's section or unit and their insurance type |
| **Condición** | Whether the appointment was a regular booking or an overbooking — see below |

---

## Filtering the History

<Steps>
  <Step title="Navigate to Panel Admin → Historial Horas">
    Open the attendance history from the main sidebar. The page loads showing all confirmed appointments for the current calendar month by default.
  </Step>
  <Step title="Set the Desde (from) date">
    Click the **Desde** date field and select the start of your desired date range.
  </Step>
  <Step title="Set the Hasta (to) date">
    Click the **Hasta** date field and select the end of your desired date range.
  </Step>
  <Step title="Optionally select a Box">
    Use the **Box** dropdown to narrow results to a single clinical box (Box 1 through Box 5). Leave it set to **Todos los Boxes** to see appointments across all boxes.
  </Step>
  <Step title="Optionally enter a patient RUT">
    Type a patient's RUT into the **RUT Paciente** field to filter results to that individual. Partial RUTs are supported — entering `12345` will match any RUT containing that sequence.
  </Step>
  <Step title="Click Filtrar">
    Click the **Filtrar** button to apply your filters. The table updates to show only records matching your criteria.
  </Step>
  <Step title="Click Limpiar to reset">
    Click **Limpiar** to clear all active filters and return to the default view — the current month, all boxes, all patients.
  </Step>
</Steps>

<Tip>
  To generate a monthly report for a specific box, set **Desde** to the first day of the month and **Hasta** to the last day, then select the box from the dropdown. The resulting table gives you a complete per-box attendance record for that period.
</Tip>

---

## Understanding the Condition Column

The **Condición** column shows how each appointment was booked:

| Badge | Colour | Meaning |
|-------|--------|---------|
| **Normal** | Green | A standard appointment scheduled within the regular time-slot grid |
| **Sobrecupo** | Red | An overbooking appointment added on top of an already-occupied slot, used when a patient needs to be seen outside normal capacity |

Sobrecupo appointments are tracked separately here so you can monitor how frequently overbooking is used.

<Note>
  The history only shows confirmed appointments. Appointments that were deleted after being scheduled do not appear in this view. To investigate deletions, refer to the Audit Log.
</Note>
