The Audit Log is your health center's tamper-evident record of every significant action performed inside SIGAS. Every time an administrator schedules an appointment, deletes a patient, creates a new account, or changes a specialist's profile, the system writes a timestamped entry to the log — recording exactly who did it, when, and what the full details were. Use the audit log to investigate incidents, verify that deletions were authorised, and maintain accountability across your administrative team.

## Accessing the Module

Navigate to **Panel Admin → Auditoría** from the main sidebar.

---

## What Gets Logged

The following action types appear in the audit log:

| Action | Description |
|--------|-------------|
| `AGENDAR` | Appointment scheduled |
| `AGENDAR_CITA` | Patient appointment created |
| `CITA_SOBRECUPO` | Overbooking appointment created |
| `ELIMINAR` | Appointment deleted |
| `ELIMINAR_CITA` | Appointment deleted |
| `DERIVACION` | Mammography referral created |
| `MAMOGRAFIA` | Mammography referral status changed |
| `RESERVA_SALA` | Box or room reservation created |
| `CREAR_ADMIN` | New administrator account created |
| `EDITAR_ADMIN` | Administrator account edited |
| `ELIMINAR_ADMIN` | Administrator account deleted |
| `CREAR_ESP` | New specialist created |
| `EDITAR_ESP` | Specialist profile edited |
| `ELIMINAR_ESP` | Specialist deleted |
| `ELIMINAR_PACIENTE` | Patient record deleted |

<Note>
  The audit log displays the **150 most recent entries**. Older records are preserved in the database but are not visible in the interface. If you need to retrieve older entries for compliance or investigation purposes, contact your system administrator.
</Note>

---

## Reading the Audit Log

The log table contains four columns:

| Column | Description |
|--------|-------------|
| **Fecha y Hora** | The exact date and time the action was performed, in `DD/MM/YYYY HH:MM:SS` format |
| **Administrador** | The full name and RUT of the administrator who performed the action |
| **Acción** | A colour-coded badge showing the action type (e.g., `AGENDAR_CITA`, `ELIMINAR_PACIENTE`) |
| **Detalle de la Operación** | A plain-language description of exactly what was done, including patient RUT, box number, appointment times, specialist names, and any other relevant identifiers |

The **Detalle de la Operación** column is the most useful for investigations — it contains the full context of the operation so you can reconstruct exactly what happened without needing to cross-reference other parts of the system.

---

## Filtering by Action

Use the **Filtrar Acción** dropdown at the top of the audit log page to narrow the view to a specific action type. The available filter options are:

- **Todas las acciones** — show the full log (default)
- **Agendar Cita** — appointments scheduled
- **Eliminar Cita** — appointments deleted
- **Derivación Mamografía** — mammography referrals created
- **Cambio Estado Mamografía** — mammography referral status updates

Selecting an option reloads the page to show only entries matching that action. To return to the full log, click **Limpiar** or select **Todas las acciones** from the dropdown.

<Tip>
  To investigate a specific incident, filter on the relevant action type (for example, **Eliminar Cita** to see all deleted appointments, or **Derivación Mamografía** to trace referral activity). Then check the **Administrador** column and the **Fecha y Hora** to confirm who acted and when.
</Tip>

<Warning>
  Audit log entries cannot be deleted or modified through the SIGAS interface. They provide a permanent, tamper-evident record of all system activity. No administrator — regardless of their permissions — can remove or alter a log entry.
</Warning>
