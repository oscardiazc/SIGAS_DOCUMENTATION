The Specialists module lets you manage the healthcare professionals available for appointment scheduling in your health center. Each specialist is linked to one or more **care types** (tipos de atención), and SIGAS uses those assignments to determine which specialists appear in the scheduling form when a particular care type is selected. Keeping this list accurate ensures that every care type can always be booked.

## Accessing the Module

Navigate to **Panel Admin → Especialistas** from the main sidebar.

---

## Specialist Fields

Each specialist profile contains the following information:

| Field | Description |
|-------|-------------|
| **RUT** | Chilean national identity number — the specialist's unique identifier in the system |
| **Nombre** | The specialist's full name as it appears in appointment records |
| **Cargo / Especialidad / Título** | The specialist's professional title or role (e.g., *Médico Cirujano*, *Enfermera*, *Psicóloga*) |
| **Foto de Perfil** | An optional circular profile photo uploaded and cropped in-browser |
| **Tipos de Consulta que Atiende** | The care types this specialist can attend — at least one is required |

---

## Adding a Specialist

<Steps>
  <Step title="Go to Panel Admin → Especialistas">
    Open the specialist directory from the main sidebar.
  </Step>
  <Step title="Click + Nuevo Especialista">
    Click the **+ Nuevo Especialista** button in the top-right corner. The Add Specialist form opens.
  </Step>
  <Step title="Enter the specialist's details">
    Fill in the specialist's **RUT** (format: `12.345.678-9`), **full name**, and **Cargo / Especialidad / Título**. All three fields are required.
  </Step>
  <Step title="Select care types">
    In the **Tipos de Consulta que Atiende** section, check every care type this specialist can provide. You must select at least one — saving without a care type is not allowed.
  </Step>
  <Step title="Upload a profile photo (optional)">
    Click **Choose File** under **Foto de Perfil**, select an image from your computer, then use the circular crop tool to frame the photo. Click **Aplicar Recorte** to confirm the framing. If you skip this step, a placeholder avatar showing the specialist's initial is displayed instead.
  </Step>
  <Step title="Click Guardar">
    Click **Guardar** to save the profile. The specialist is immediately available in the scheduling form for any care type you assigned.
  </Step>
</Steps>

---

## Editing a Specialist

To update a specialist's details, click their row in the directory table. A profile popup appears showing their name, RUT, title, and assigned care types. Click **Editar** to open the edit form.

In the edit form you can:

- Update the specialist's name, RUT, or title
- Adjust the care type assignments by checking or unchecking items
- Replace the profile photo using the circular crop tool

Leave the photo field unchanged to keep the existing image. Click **Guardar** to apply your changes — the directory updates immediately.

---

## Deleting a Specialist

To remove a specialist from the system, open their profile popup and click **Eliminar**. You will be prompted to enter your administrator password to confirm.

<Warning>
  Deleting a specialist requires your administrator password and is permanent. The action is recorded in the audit log. Past appointments that referenced this specialist retain their data — only future scheduling is affected.
</Warning>

Enter your password and click **Confirmar Baja**. The specialist is removed and the page reloads.

---

## Care Type Assignment

Care type assignment is the link between a specialist and the scheduling system. When an administrator opens the scheduling form and selects a care type, SIGAS shows only the specialists who have that care type assigned.

This means:

- A specialist only appears as an option when their assigned care type is selected.
- If no specialist is assigned to a care type, that care type **cannot be scheduled** — the specialist dropdown will be empty.
- A single specialist can cover multiple care types if needed.

Always review care type assignments after adding a new specialist or when staff responsibilities change.

<Note>
  If no specialist is assigned to a care type, that care type cannot be scheduled. Ensure at least one specialist is always assigned to every active care type in your health center.
</Note>
