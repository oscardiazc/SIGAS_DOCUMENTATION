Scheduling a patient appointment in SIGAS takes you through a single form that collects patient data, assigns the correct clinical box based on the care type you choose, and presents only the available time slots — so you never accidentally double-book a box. Once you save the appointment, it appears on the dashboard grid immediately.

## Before You Begin

Make sure the following conditions are met before opening the scheduling form:

- The patient has a valid **Chilean RUT** in the format `12345678-9` (no dots, with a dash before the verification digit).
- The **care type** you intend to book is active in the system.
- At least one **specialist** is registered and assigned to that care type. If no specialists appear in the dropdown, contact your system administrator.

## Scheduling a Patient Appointment

<Steps>
  <Step title="Open the scheduling form">
    Click **+ Agendar Paciente** in the top-right corner of the dashboard. The scheduling form opens with the current date pre-filled.
  </Step>
  <Step title="Enter Patient Data">
    Fill in all the patient information fields in the **Datos del Paciente** section:

    | Field | Required | Notes |
    |---|---|---|
    | **RUT Paciente** | Yes | Format: `12345678-9` — no dots, with dash. |
    | **N° Folio** | No | Optional reference number (e.g., `F-1024`). |
    | **Nombres** | Yes | Patient's first name(s). |
    | **Apellidos** | Yes | Patient's last name(s). |
    | **Teléfono** | Yes | Contact phone number. |
    | **Correo Electrónico** | No | Patient's email address. |
    | **Sección / Unidad** | Yes | The department or unit the patient belongs to. |
    | **Previsión** | Yes | Health coverage — choose from: FONASA A, FONASA B, FONASA C, FONASA D, ISAPRE, CAPREDENA, DIPRECA, or PARTICULAR. |

    <Note>
      After you type a RUT and move to the next field, SIGAS automatically searches the patient database. If a match is found, the form fills in the patient's name, last names, phone, email, section/unit, and previsión automatically. You can update any pre-filled value before saving — SIGAS overwrites the patient record with the new values when the appointment is confirmed.
    </Note>
  </Step>
  <Step title="Select Care Type and Confirm Auto-Assigned Box">
    In the **Configuración de Atención en Box** section, open the **Tipo de Atención** dropdown and select the appropriate care type. The system immediately determines the correct clinical box based on your selection — the **Box Asignado** field fills in automatically and is read-only. You do not choose the box yourself.

    Each care type has a fixed appointment duration:

    | Care Type | Duration | Auto-Assigned Box |
    |---|---|---|
    | Toma de Muestras | 10 min | Box Procedimientos |
    | EMP | 30 min | Box Procedimientos |
    | Dental | 60 min | Box Dental |
    | Morbilidad | 20 min | Box Médico |
    | Certificados | 10 min | Box Médico |
    | Salud Mental USIT | 60 min | Box Salud Mental |
    | Kinesiología | 30 min | Box Rehabilitación |
  </Step>
  <Step title="Select a Specialist">
    Open the **Especialista** dropdown. The list is automatically filtered to show only specialists who are registered and active for the selected care type. Choose the specialist who will attend this appointment.
  </Step>
  <Step title="Pick a Date and Time Slot">
    Select the appointment date using the **Fecha** date picker. The **Bloque Horario Disponible** dropdown then loads all available time slots for the auto-assigned box on that date — only free slots are shown. Select the desired time block.
  </Step>
  <Step title="Save the Appointment">
    Click **Guardar Cita**. SIGAS validates the slot one final time against the current schedule. If the slot is still free, the appointment is confirmed and you are redirected to the dashboard, where the new appointment block appears immediately in the correct box column.
  </Step>
</Steps>

## Mammography Referral

If the patient needs an external mammography referral instead of a clinical box appointment, check the **¿Es derivación externa a Mamografía? (No ocupa Box)** checkbox before saving. When this box is checked, the **Configuración de Atención en Box** section is hidden and no box slot is reserved. Saving the form registers the patient in the mammography waiting list without occupying any clinical box or creating a dashboard appointment block.

<Tip>
  A mammography referral and a box appointment are mutually exclusive in the same form submission. If a patient needs both, submit the mammography referral first, then return to the scheduling form and book the box appointment separately.
</Tip>
