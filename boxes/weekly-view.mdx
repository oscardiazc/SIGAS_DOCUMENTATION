The weekly box view gives you a detailed, day-by-day look at every confirmed appointment scheduled in a single clinical box. Use it to spot gaps in the week ahead, verify that a specialist's schedule is correctly loaded, or identify the best moment to fit in an additional patient before the week fills up.

## Accessing the Weekly View

<Steps>
  <Step title="Open the Horarios Boxes menu">
    In the top navigation bar, click **Horarios Boxes**. A dropdown appears listing all five clinical boxes by name.
  </Step>
  <Step title="Select a box">
    Click the box you want to inspect — for example, **Box Procedimientos**, **Box Dental**, **Box Médico**, **Box Salud Mental**, or **Box Rehabilitación**. SIGAS opens the weekly schedule for that box, defaulting to the current week.
  </Step>
</Steps>

## What the Weekly View Shows

The weekly view renders a calendar grid with one column per working day, Monday through Friday. Each column covers the full working day for the selected box from **08:00 to 17:00**, with the 13:00–14:00 lunch break excluded from bookable time.

- **Day columns** — each column is labelled with the day name and the calendar date (e.g., *Lunes 14/07*).
- **Appointment blocks** — confirmed appointments appear as color-coded blocks positioned vertically according to their start time. Block height reflects the duration of the care type, so a 60-minute Dental appointment is taller than a 20-minute Morbilidad consultation.
- **Patient label** — each block displays the patient's full name. Sobrecupo appointments also show a **[S]** suffix directly on the block.
- **Tooltip details** — hover over any block to see the full time range, patient name, and care type without opening the detail panel.
- **Click to inspect** — click any block to open the appointment detail panel, which shows the patient's RUT, contact information, health insurance (previsión), unit, care type, time range, and sobrecupo status.

<Note>
  Each box has its own independent weekly view. Selecting Box Dental, for example, shows only dental appointments — other boxes are not visible from that view.
</Note>

## Navigating Between Weeks

The navigation controls sit in the top-right corner of the weekly view:

| Control | Action |
|---|---|
| **← Semana Anterior** | Move back one week |
| **Hoy** | Jump to the week containing today |
| **Semana Siguiente →** | Move forward one week |
| **Vista Mensual** | Switch to the monthly view for the same box |

The header also shows the date range of the currently displayed week (e.g., *Semana del 14/07/2025 al 18/07/2025*) so you always know exactly which period you are viewing.

## Switching Between Boxes

Every box's schedule is accessed independently. To switch from one box to another, use the **Horarios Boxes** dropdown in the top navigation and select a different box. The dropdown always lists all five boxes in the same order:

1. Box Procedimientos
2. Box Dental
3. Box Médico
4. Box Salud Mental
5. Box Rehabilitación

Each selection opens that box's schedule at the current week.

## Interpreting Appointment Colors

Each care type has a fixed color that appears consistently across the weekly and monthly views:

<Accordion title="Color legend">

  | Care Type | Color |
  |---|---|
  | Toma de Muestras | Cyan (#00BCD4) |
  | EMP | Green (#4CAF50) |
  | Dental | Pink (#E91E63) |
  | Morbilidad | Blue (#2196F3) |
  | Certificados | Orange (#FF9800) |
  | Salud Mental USIT | Purple (#9C27B0) |
  | Kinesiología | Teal (#009688) |
  | Reserva de Box / Sala | Dark grey (#4A5568) |

</Accordion>

<Accordion title="Empty columns">
  A day column with no appointment blocks means the box has no confirmed appointments on that date. This is normal for public holidays or days when the assigned specialist is not scheduled.
</Accordion>

<Accordion title="Sobrecupo appointments">
  Sobrecupo (overflow) appointments appear in the same color as standard appointments but carry a **[S]** label on the block. When a sobrecupo appointment overlaps with a regular appointment in the same column, both blocks remain visible — the blocks may visually overlap to signal the time conflict.
</Accordion>

## Scheduling Directly from the Weekly View

You can click any **empty segment** in a day column to open the appointment scheduling form pre-filled with the selected box, date, and the nearest 10-minute time slot. This lets you book a new appointment without leaving the weekly view.

<Tip>
  Use the weekly view to identify the best days to schedule high-demand care types before opening appointments to patients.
</Tip>
